# music_page_agent — 网易云远控代理

跑在 Windows 电脑上的 Python 小服务，把网易云音乐正在播放的歌交给 ESP32
音乐页显示，并转发板子的切歌/播放指令。板端无需任何配置，靠 UDP 广播自动
发现电脑。

曲目信息取自网易云主窗口标题（"歌名 - 歌手"），播放/暂停状态取自系统媒体
会话（SMTC），控制指令用系统媒体键（等价于键盘上的多媒体键）。之所以不用
SMTC 读曲目：实测网易云 3.x 的媒体属性是**冻结**的（一直报同一首歌），切歌
API 也不工作。

## 安装与启动

```powershell
cd tools\music_page_agent
pip install -r requirements.txt
python music_agent.py          # 默认端口 8777
python music_agent.py --port 9000
```

首次启动 Windows 防火墙会弹窗，选择"允许访问"（需要放行 UDP 9878 和 TCP 端口）。

## 要求

- 网易云音乐 Windows 客户端处于登录且**正在运行**（代理按窗口标题取曲目，主窗口最小化到托盘也可以）。
- 电脑和板子连同一个局域网（同一网段，路由器未开 AP 隔离）。
- Pillow 用于生成封面和背景小图；未安装时状态与控制仍可用，只是没有封面。
- 歌词：按"歌名+歌手+时长"搜网易云公开接口取 LRC，按播放进度把当前句放进 `/state`；
  搜不到或网络失败时该字段为空，板子显示"暂无歌词"。

## 常见问题

**只打开网易云、板子没反应？** 正常——网易云不会主动通知板子。板子只认本代理：
必须先 `python music_agent.py` 并保持运行（首次运行允许防火墙），板子会在 2 秒内
收到广播并自动连上，之后网易云一放歌状态就会过去，不需要其他任何操作。
如果代理已运行仍连不上，检查板子和电脑是否在同一网段（代理启动时会打印本机 IP）。

## 接口

| 路径 | 说明 |
| --- | --- |
| `GET /state` | 播放状态 JSON：标题/歌手/专辑/进度/是否播放/封面哈希/当前歌词行 |
| `GET /lyrics?h=<hash>` | 整首 LRC 文本（板端自己解析并滚动显示） |
| `GET /art?h=<hash>` | 240x240 JPEG 封面（不带 h 时回退到最近一首的封面） |
| `GET /art_blur?h=<hash>` | 96x34 RGB565 背景小图（板端放大为毛玻璃背景） |
| `POST /cmd` | `{"action":"play_pause"\|"next"\|"prev"}`；成功返回 `{"ok":true,"via":"click"}`，回退 SMTC 时 `via` 为 `"smtc"` |

板端发现机制：每 2 秒广播 `MUSICAGENT|<ip>|<port>` 到 UDP 9878；
8 秒收不到广播，板子自动转入演示模式。

## 歌词与进度是怎么来的

- **歌词**：按"标题+歌手+时长"在网易云搜索里打分挑原曲（避免挑到翻唱），
  取 `/api/song/lyric` 的 LRC 交给板端；失败 30 秒后自动重试。外语歌同时取
  翻译（tlyric），按时间戳对齐后与原文一起下发，板端显示为上下两行。
- **曲目**：读网易云主窗口标题（"歌名 - 歌手"），过滤"网易云音乐/桌面歌词/迷你播放器"
  这类页面名。窗口最小化到托盘时也能读到。
- **控制**：
  - `next` / `prev`：发系统媒体键（`WM_APPCOMMAND`：next=11、prev=12）到网易云窗口，
    和键盘多媒体键同一条链路；SMTC 的 `try_skip_*` 仅在媒体键失败时回退。
  - `play_pause`：**真点一下网易云界面底部的圆形播放键**（`SendInput` 鼠标点击，
    位置固定在客户区 `(宽度/2, 高度-43)`）。原因见下面"踩坑"——暂停之后任何
    SMTC 的 play/toggle、合成媒体键都会把歌换成随机一首，只有真点按钮才原曲续播。
    副作用：点的时候网易云会抢一次窗口焦点（鼠标位置会还原）。
    窗口最小化/尺寸过小时点不到，此时暂停仍走 SMTC（安全），恢复播放只能退回
    SMTC 并接受"可能换歌"。
- **进度**：网易云的 SMTC *不给时间线*（`get_timeline_properties()` 的 position/end_time 恒为 0、
  last_updated 停在 1601 年），调试端口里也没有 `<audio>` 元素（.NET 原生播放），
  所以进度由代理的**本地时钟**推算：切歌归零、暂停冻结、播放累加、单曲循环按
  "超出时长 3 秒"绕回。**在电脑上拖动进度条无法感知**，屏幕进度会从拖之前的位置继续走。
- **播放状态**：winrt 的 `playback_status` 枚举 `str()` 出来是数字（"4" 才是播放中），
  不能用字符串判断。
- **依赖**：只用 `aiohttp` + `Pillow`（下载/缩放封面）；没有任何截图或 OCR 依赖。

## 踩坑（都是实测踩出来的）

- **暂停之后，"播放"这个动作在网易云上不能用任何 API 表达**：`try_play_async`、
  `try_toggle_play_pause_async`、合成媒体键（`WM_APPCOMMAND` 14/46）三者都会把歌
  **换成随机一首**（随机播放开着时最明显；用户看到的就是"点播放变成切歌"）。
  唯一可靠的做法是用 `SendInput` 真点界面底部那颗圆形播放键，和用户手动点完全一致。
  `PostMessage` 合成鼠标消息 CEF 不认，必须 `SendInput`。
- 播放键位置：客户区 1168x830 时圆心在 `(584, 787)` = `(宽度/2, 高度-43)`；
  客户区小于 600x300 时不要点（宁可退回 SMTC），避免点到别的按钮。
- 网易云的 SMTC 媒体属性是**冻结**的（一直报上一首），只有 `playback_status` 可信；
  曲目必须读窗口标题。

## 验证

电脑上用任意浏览器打开 `http://127.0.0.1:8777/state`，播放一首歌应能看到
JSON 里的标题和进度变化；`GET /art?h=<state 里的 art_hash>` 应返回封面图。
